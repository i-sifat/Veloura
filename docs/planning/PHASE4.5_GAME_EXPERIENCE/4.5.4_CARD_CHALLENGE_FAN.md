## 0. Rules

Same 11 rules as 4.5.1 §0. Additionally:

  categories) is reused untouched. Card states (locked / available / in-progress / completed),

## 1. The intensity mapping (no new data)

The reference design deals three cards labelled SENSUAL / SEXY / SUPERHOT so that **choosing a card is
choosing a heat level**. Derive those three decks from the existing `Difficulty` enum:

```
SENSUAL   <- Difficulty.cute + Difficulty.romantic
SEXY      <- Difficulty.spicy
SUPERHOT  <- Difficulty.extreme          (premium + consent-gated)
```
Category remains an independent axis and is not shown on the card back. If a session filter narrows
categories, the three cards are drawn from within that filter.

If `extreme` is unavailable (no premium, or "Soften decks" on), the third card is drawn from `spicy`
and its back shows a `PremiumLockBadge`.

## 3. `CardFan`

```
card 132 x 196 · radius 18
positions relative to the fan centre:
  left    offset (-78, 14)   rotation -10 deg   scale 0.96   z 0   -> SENSUAL
  centre  offset (  0,  0)   rotation   0 deg   scale 1.00   z 2   -> SEXY
  right   offset ( 78, 14)   rotation +10 deg   scale 0.96   z 1   -> SUPERHOT
entry: staggered 60ms, slide up 24px + fade, cardFan (420ms easeOutCubic)
idle: the centre card floats +/-3px vertically over 2600ms (breathe)
```
Left-to-right order is always ascending heat, so position communicates escalation without copy.

### Card back
```
gradient 150 deg: [deck.base, deck.base darkened 18%]
border 1.5px deck.glow @ 55%
outer glow: BoxShadow(deck.glow @ 28%, blur 18, spread -2)
inner hairline 1px #FFFFFF @ 10%, inset 5, radius 14
centred column, padding 14:
  deck label   cardLabel, #FFFFFF @ 92%, uppercase
  10
  deck glyph   30px svg (heart_spark / chili / flame), #FFFFFF @ 88%
top-right: 3px rounded tick mark, deck.glow @ 40%
```

### Pick and reveal
1. Tap -> `lightImpact`. The two unpicked cards translate +/-120px outward and fade to 0 over 260ms.
2. The picked card moves to centre and scales to 1.14 (300ms easeOutCubic).
3. Flip: `rotateY` 0 -> `pi` over 620ms (`cardFlip`), perspective 0.0012. Swap the child at `t > 0.5`
   and counter-rotate the front child by `pi` so text is not mirrored. `mediumImpact` on completion.
4. Revealed face:
```
208 x 300 · radius 20 · fill sheet · border 1px deck.glow @ 45% · cardGlow shadow
padding 20, column:
  deck chip      height 24, radius 12, deck.glow @ 18% fill, cardLabel in deck.glow
  Spacer
  title          promptBody, centred, maxLines 2
  8
  description    bodyMid, textSecondary, centred, maxLines 4, FittedBox(BoxFit.scaleDown)
  Spacer
  time chip      glass, caption, from the card's existing estimated-time field
```
   Title and description come straight from the existing `ChallengeCard` model — no new fields.
5. Below the card, 20 gap:
   - `PrimaryCta("Done")` -> runs the **existing completion flow** (optional reflection note + reward
     event) -> `nextTurn()` -> re-deal with a 420ms riffle.
   - `SecondaryTextButton("Skip")` always present: no dialog, no penalty, re-deals and advances.
   - `SecondaryTextButton("Swap card")`: premium-gated, once per turn.
   - Share stays available as an icon in the sheet, using the existing `share_plus` output.
