## 1. What is actually wrong today

From the device screenshot of the current Dice screen:
- The result is printed **twice** — once under the tray and again as the first history row.
- Three secondary controls sit below the primary action: an "Add intensity / time die" toggle row, a
  locked "Custom dice faces" premium row, and a "Roll history" list.
- Nothing indicates that two people are playing or whose turn it is.
- The screen title is "Dice", which reads like a utility, not a game.

## 2. What the game is (so the UI can stop explaining it)

A **two-die action composer**. Die A carries verbs, die B carries targets. One throw produces one
instruction for the active player to perform on their partner:

```
Anna -> Daniel :  "Hold their neck"
```

Consequences that must be implemented exactly:
- **One tap throws both dice at once.** The player never picks twice, never chooses a verb and then a
  target, and never chooses who performs it. The turn alternates automatically.
- The optional third die stays OFF by default and is toggled only from `GamePreferencesSheet`.
- The screen is renamed **Lustful rolls** at `/games/lustful-rolls`. The module folder stays
  `lib/features/dice`.

## 4. `BoardBackdrop` (the one new visual)

Enabled through `GameShell(board: true)`. Layers, bottom to top:
1. `GameBackdrop` base gradient.
2. Table glow: `Align(Alignment(0, 0.12))`, size `boardWidth * 0.92` x `boardWidth * 0.86`,
   `RadialGradient([#6B1C6F @ 42%, transparent])`, blurred with
   `ImageFiltered(ImageFilter.blur(sigmaX: 28, sigmaY: 28))`. This is a static layer, so the blur is
   safe — it is **not** a `BackdropFilter` and it does not sit over the animating cube.
3. Felt texture: `assets/games/felt_noise.png`, `ImageRepeat.repeat`, opacity 0.05,
   `BlendMode.overlay`.
4. Board frame: rounded rect inset 16 from the board area, radius 28, 1px border `#FFFFFF @ 8%`; a
   second rrect paints `#000 @ 22%` at 12px blur along the top edge only to fake an inner shadow.
5. Two faint rose glows at `Alignment(-0.70, -0.50)` and `Alignment(0.75, 0.40)`, radius 0.45,
   `rose @ 10%`, blur 40.

All five layers are static. Put them behind the cube's `RepaintBoundary` so they never repaint during
a throw — verify in the devtools layer view before opening the PR.
